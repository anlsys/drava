# PtychoPINN example dependencies.
#
# Versions are intentionally loose. Unlike the TensorFlow examples, this one
# pulls in a large scientific stack whose correct build depends on the CUDA
# toolkit loaded on the node, so pinning an exact torch wheel here would be
# wrong more often than right. Install torch first, matched to the node's CUDA,
# then the rest:
#
#     pip install torch --index-url https://download.pytorch.org/whl/cu121
#     pip install -r requirements.txt
#
# See README.md for the free-threaded-Python caveat on JLSE.

# --- Drava publisher/runtime side -------------------------------------------

PyYAML>=6.0

# --- PtychoPINN model + inference -------------------------------------------
# torch is installed separately (see above) so the CUDA build is explicit.

mlflow>=2.12

# --- Data handling ----------------------------------------------------------

scipy>=1.11

# --- Evaluation (FRC) -------------------------------------------------------
